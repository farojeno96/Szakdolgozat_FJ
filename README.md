A Szakdolgozati kódok file tartalmazza a szakdolgozat legtöbb ábráját, melyek az elméleti megközelítéssel kapcsolatosak
Az Empirical_application_1 és _2 file-ok pedig az empirikus változatát tartalmazzák a szakdolgozatban javasolt kockázatossági indexnek: 
az 1-es file-ban valós adatokkal zajlanak az elemzések, 
a 2-esben pedig többdimenziós normális eloszlásból szimulált adatokon.
